# Engineering Onboarding Guide

Welcome to the Acme Engineering team! This guide will help you get started.

## Week 1: Setup

- Receive laptop and credentials
- Set up development environment
- Complete security training
- Meet your team and manager

## Development Tools

We use:
- Git for version control
- Jira for project tracking
- Slack for communication
- AWS for cloud infrastructure

## Code Review Process

All code changes must be reviewed by at least one other engineer before merging. Use pull requests in GitHub.

## Support

If you have questions, reach out to your buddy or post in #engineering-help on Slack.
